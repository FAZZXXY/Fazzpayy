Bantuan & FAQ

Bagaimana cara transfer ke user lain?
Buka menu Kirim atau tab PAY, masukkan username tujuan, jumlah, dan PIN Anda. Saldo akan langsung terkirim.
Berapa minimal transfer?
Minimal transfer Rp 1. Tidak ada biaya admin untuk sesama pengguna DompetKu.
Lupa PIN, bagaimana?
Untuk demo ini, PIN default adalah 123456. Di aplikasi nyata, hubungi customer service untuk reset PIN.
Apakah data saya aman?
Aplikasi demo ini menyimpan akun, saldo, dan transaksi di Firebase Realtime Database agar dapat digunakan dari perangkat berbeda.
Bagaimana cara top up saldo?
Buka menu Top Up, masukkan jumlah, klik Top Up. Saldo bertambah instan (simulasi).
